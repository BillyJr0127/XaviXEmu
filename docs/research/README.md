# Research notes

These notes preserve the real investigation trail: observed symptoms,
addresses, hardware interfaces, hypotheses, experiments, results, and code
changes. They may contain ROM offsets and identification hashes, but no ROM
data, screenshots, save files, memory dumps, or large generated disassembly.

The notes describe milestones, not blanket compatibility claims. Current user
expectations are documented in `../compatibility.md`.
